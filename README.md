# Virr Gold Marketplace

Разработваме онлайн магазин за продажба на инвестиционно злато. Онлайн магазина ще е подстраница в web страницата на Virr.io. 
Планирам да сложа линк към подстраницата в menu bar-a. 
Ще продаваме златни кюлчета, инвестиционни монети, монети с нумизматична стойност и други 
Разгледай най-популярните онлайн магазини и създай магазин, който е user friendly и с хубав дизайн, да има подходящи филтри и очакваните от потребителите функционалности. Спази всички добри практики за да е функционален магазина и приятен за очите на ползващите го.
Прилагам екран от web страницата на Virr за да се ориентираш в бранд цветовете
